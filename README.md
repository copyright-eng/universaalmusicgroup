# Music rights website

Static site (HTML, CSS, JS). No build step.

- `index.html` : page content (menu, news, footer, text in the middle)
- `style.css` : design
- `script.js` : artist slideshow (edit the `artists` list at the top)
- `assets/` : logo and artist photos

Preview locally: open `index.html` in a browser.
Deploy: GitHub Pages (Settings > Pages > Deploy from branch > main / root).
